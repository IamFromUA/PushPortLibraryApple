# Security

Report vulnerabilities privately to support@pushport.dev. Include affected version, reproduction steps and a synthetic example. Do not post credentials, device tokens, private keys or customer data in public issues.

The App ID is public. Installation credentials are private and must not appear in URLs, analytics or logs. Platform provider credentials belong to the backend. HTTPS is mandatory outside explicitly supported local development. Applications remain responsible for their host process/origin security, privacy disclosure and notification permission UX.

Version 0.0.1 is pre-publication. It has no production-support guarantee until the native/consumer release gates described in the repository pass.
